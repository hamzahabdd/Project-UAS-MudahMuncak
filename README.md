# Website MudahMuncak

# Struktur Folder
1. beranda.html - Halaman utama
2. admin.html - Halaman Admin
3. kategori.html - Halaman katagori gunung
4. kontak.html - Halaman kontak MudahMuncak
5. login.html - Halaman Login untuk user dan admin
6. profile.html - halaman profile user
7. css/base.css - Pengaturan dasar dan variabel CSS
8. css/components.css - Tampilan header, tombol, kartu, dan layout
9. css/login.css - Untuk tampilan login
10. css/profile.css - Untuk tampilan profile

# Cara Menjalankan
Buka folder proyek ini di VS Code.
Cari file bernama index.html.
Klik dua kali pada file index.html tersebut.
File akan otomatis terbuka dan berjalan langsung di browser (peramban) pilihan Anda (google chrome, microsoft edge)
